# Biz Box

This is the cleaned source project for Biz Box.

## Deploy to Vercel
Import this repository/project with the repository root set to this folder. The Vite app entry is `src/main.tsx`.

## Local setup
1. `npm install`
2. `npm run dev`
3. `npm run build`

## Supabase
The original UI currently uses its existing client-side state. Supabase preparation can be added after deployment. Do not add production secrets to the repository.
